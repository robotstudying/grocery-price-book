# 猴价钱 🐵

一个**单文件 HTML** 的买菜比价小工具，无需安装任何依赖，浏览器打开即用。支持添加到 iPhone / Android 主屏幕，作为 PWA 使用。

> 线上地址：https://robotstudying.github.io/grocery-price-book/

## 功能

- **商品管理**：按分类（食品 / 日用品等）和细分类组织商品，支持品牌、规格、备注
- **多门店比价**：每个商品记录多家门店的价格，自动标出**最便宜的门店**
- **价格历史**：每次改价自动留存历史记录，标注「平 / 涨 / 降」趋势
- **购物清单**：勾选要买的商品，生成按门店分组的购物清单
- **数据备份**：一键导出 / 导入 JSON，跨设备搬家不丢数据
- **规格候选**：录入规格时提供重量 / 容量两行候选，点选即填

## 特点

| 项目 | 说明 |
|---|---|
| 零依赖 | 全部代码、图标（base64 内联）都在一个 HTML 文件里 |
| 离线可用 | 数据存在浏览器 IndexedDB，断网也能打开 |
| PWA 支持 | 添加到主屏幕后全屏运行，无地址栏 |
| 移动端优化 | 16px 输入字号防 iOS 自动缩放、底部安全区适配（safe-area） |

## 使用方式

### 手机（推荐）

1. 用 Safari（或任意浏览器）打开线上地址
2. **iPhone**：分享 → 添加到主屏幕
3. 从主屏幕图标进入，就是一个独立 App

### 数据搬家 / 备份

- 点底部功能栏 **💾 备份** → 导出 JSON 文件
- 在另一台设备打开本工具 → 点 **📥 导入** → 选择 JSON 文件即可恢复

> ⚠️ 数据保存在浏览器本地（IndexedDB）。清理浏览器数据、卸载 App 前请先备份。

## 本地运行

无需构建，直接用浏览器打开 `index.html` 即可；或起一个本地静态服务：

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 技术说明

- 单文件实现：HTML + CSS + 原生 JavaScript，无框架、无构建流程
- 存储：IndexedDB（`grocery_db`），含商品、门店、价格历史
- 视口适配：`100dvh` + `env(safe-area-inset-*)`，兼容 iOS PWA 独立模式
- 版本号显示在页面右上角徽章，格式 `v<月日>.<当日序号>`
